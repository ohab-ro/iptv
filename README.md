# OHAB IPTV — PS4 Web Host

واجهة IPTV خفيفة مصممة لتعمل من GitHub Pages أو أي استضافة HTTPS، مع مراعاة قيود متصفح PS4.

## المزايا
- Xtream Codes عبر `player_api.php?action=get_live_streams`
- M3U/M3U8 عبر رابط أو ملف محلي
- تصنيفات القنوات، البحث، الفرز، والمفضلة
- حفظ المفضلة وبيانات Xtream اختياريًا في `localStorage`
- مؤشر اتصال الإنترنت وساعة محلية
- مشغل HTML5 أصلي؛ يعتمد على قدرات متصفح PS4 الفعلية
- بدون Frameworks أو Build tools لتقليل الحمل وزيادة التوافق
- إعادة محاولة للبث ورسائل خطأ واضحة

## تشغيل GitHub Pages
1. أنشئ Repository جديدًا.
2. ارفع `index.html`, `style.css`, `app.js`.
3. من Settings → Pages اختر النشر من الفرع المطلوب.
4. افتح رابط GitHub Pages في متصفح PS4.

## مهم: CORS والبث
GitHub Pages لا يعمل كـ proxy. إذا كان رابط M3U أو API الخاص بـXtream لا يسمح بطلبات من أصل مختلف (CORS)، فقد يرفض المتصفح التحميل. الحل يكون من إعدادات مزود الخدمة أو استخدام استضافة/Proxy تملكه وتسمح به الخدمة.

## توافق الصيغ
لا يوجد مشغل ويب يستطيع ضمان تشغيل كل ترميزات الفيديو والصوت على PS4. أفضل فرصة للتوافق تكون عادة مع HLS/M3U8 وترميزات مدعومة أصليًا من متصفح PS4، خصوصًا H.264/AAC. روابط TS المباشرة من Xtream قد تعمل أو لا تعمل بحسب السيرفر والترميز.

## ملاحظة أمنية
حفظ بيانات Xtream اختياري. إذا فعلته، تُحفظ محليًا في متصفح الجهاز عبر `localStorage`. لا تفعل ذلك على جهاز مشترك.
